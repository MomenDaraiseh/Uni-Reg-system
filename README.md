# Internal-GPS-system
Developed a campus-wide internal navigation system in C++ using custom graph data structures to model buildings, floors, rooms, and pathways across the university.
Implemented Breadth-First Search (BFS) for shortest-path traversal in an unweighted graph, enabling efficient multi-floor
navigation between any two campus locations.
Designed file-based data storage and retrieval mechanisms for maintaining persistent location and routing information without
a database dependency.
